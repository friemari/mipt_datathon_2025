## Кейс: Создание прогнозной модели для онлайн-магазина: предсказание прибыльности пользователя на основе истории покупок и возвратов

## Описание проекта  

_Компания:_ онлайн-магазин с широкой линейкой товаров и развитой системой доставки и возвратов.  

_Продукт:_ платформа e-commerce, которая стремится повысить прибыльность клиентской базы и снизить затраты на обслуживание возвратов. Решение задачи встроено в систему аналитики и персонализации маркетинга, чтобы выявлять сегменты пользователей с высоким и низким прогнозируемым вкладом в прибыль.  

_Проблема продукта:_ Магазин сталкивается с тем, что значительная доля клиентов генерирует убытки из-за частых возвратов и низкой маржинальности покупок. Это снижает общий показатель LTV (Lifetime Value) и искажает прогнозы финансового роста.  

## Описание датасета  

В файле содержатся данные о пользователях на дату среза и прибыльности в течение следующего месяца после даты среза.  

Колонки в данных:  
• user_id — id пользователя;  
• platform_num — количество устройств, с которых пользователь входил в личный кабинет;  
• first_login — дата первого логина;  
• reg_dt — дата регистрации;  
• browser — предпочитаемый браузер пользователя;  
• first_buy — дата первой покупки;  
• total_buy — общий объем покупок на момент среза;  
• total_return — общий объем возвратов на момент среза;  
• target — отношение возвратов к покупкам в течение следующего месяца после даты среза.
